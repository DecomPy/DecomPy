This readme involves the use of pytest. To properly use pytest before merging, simply type in `pytest` at the root directory.
Additionally, you must name the test class as `test_*` where `*` is the name you want. For example, `test_pass`. To run the functions
as tests, you must also have `test_*` for the function name. For example, `test_length()`. Otherwise, pytest will not be able to find it.
