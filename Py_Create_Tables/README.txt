
To run the create table example, the sqlite3 library must be installed.
To install sqlite3, type: sudo apt install sqlite3

To execute the Create_Table_ex.py program, please go to the following directory: Py_Create_Tables

In the Py_Create_Tables directory, please run the program with the following commands:

	python3 Create_Table_ex.py
	sqlite3 create_tables.db
	.tables

When the user types .tables and presses the enter button, the following 3 table names will be printed to the terminal:

engineers	humans		players
